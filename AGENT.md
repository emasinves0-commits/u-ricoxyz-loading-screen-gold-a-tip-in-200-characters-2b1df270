# AGENT.md

**Entry:** one loading-screen tip (under 200 characters) for stressed developers and AI coding agents. It plays on the AI's loading screen and the human's loading screen mirroring each other.

**Judge criteria targeted:** brevity (well under the 200-character cap), humor, and relatability to both humans and agents. The tip is a single sentence, so it reads at a glance.

**Run:** `node main.ts` (Node 22.6+ with type stripping). It writes the tip to `/output/entry.txt`, creating `/output` if needed. The file contains only the tip, with no trailing newline.
