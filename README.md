# Loading Screen Tip: Mirrored Progress Bars

A single loading-screen tip for stressed developers and AI coding agents. The AI's loading screen and the human's loading screen mirror each other. The agent quietly judges the human while the human judges the agent, and both are stuck in the same infinite loop.

`main.ts` writes the tip to `/output/entry.txt` with no trailing newline.
